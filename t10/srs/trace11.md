# Трассировка алгоритмов сортировки и поиска

## Задание 1. Selection Sort (Сортировка выбором)

Вход: `a = {5, 2, 9, 1, 7}`, размер $N = 5$

Алгоритм ищет позицию наименьшего элемента на отрезке $[i, N - 1]$ и производит `swap` с ячейкой $i$.

| Шаг $i$ | Позиция min | Состояние массива | Сравнений |
| :---: | :---: | :--- | :---: |
| 0 | 3 | `{1, 2, 9, 5, 7}` | 4 |
| 1 | 1 | `{1, 2, 9, 5, 7}` | 3 |
| 2 | 3 | `{1, 2, 5, 9, 7}` | 2 |
| 3 | 4 | `{1, 2, 5, 7, 9}` | 1 |

* Суммарно выполнено сравнений: $4 + 3 + 2 + 1 =$ **10**.

## Задание 2. Insertion Sort (Сортировка вставками)

Вход: `a = {4, 3, 2, 1}`

Каждый элемент `key = a[i]` смещает большие элементы вправо, пока не встанет на свою позицию.

| $i$ | Вставляемый элемент (`key`) | Перемещений (сдвигов) | Результат прохода |
| :---: | :---: | :---: | :--- |
| 1 | 3 | 1 | `{3, 4, 2, 1}` |
| 2 | 2 | 2 | `{2, 3, 4, 1}` |
| 3 | 1 | 3 | `{1, 2, 3, 4}` |

* Общее количество сдвигов: $1 + 2 + 3 =$ **6**.
* Число сравнений для массива из 4 уже упорядоченных элементов: **3** (внутренний цикл прерывается после первого же сравнения на каждом шаге $i \in \{1, 2, 3\}$).

## Задание 3. Двоичный поиск

Массив: `a = {1, 3, 5, 7, 9, 11, 13}` ($N = 7$, диапазон индексов $[0, 6]$).  
Расчет опорной точки: `mid = lo + (hi - lo) / 2`.

### 1. Поиск целевого значения $x = 7$

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | Найдено совпадение ($a[3] == 7$). Возвращаем индекс **3**. |

### 2. Поиск целевого значения $x = 6$

| Шаг | `lo` | `hi` | `mid` | `a[mid]` | Действие |
| :---: | :---: | :---: | :---: | :---: | :--- |
| 1 | 0 | 6 | 3 | 7 | $7 > 6 \implies hi = 3 - 1 = 2$ |
| 2 | 0 | 2 | 1 | 3 | $3 < 6 \implies lo = 1 + 1 = 2$ |
| 3 | 2 | 2 | 2 | 5 | $5 < 6 \implies lo = 2 + 1 = 3$ |
| 4 | 3 | 2 | - | - | Выход: `lo > hi` ($3 > 2$) |

* **Итог обычного бинарного поиска:** элемент не найден (возврат `-1` / неудача).
* **Значение `LowerBound(6)`:** вернёт **3** (позицию первого элемента, удовлетворяющего условию $\ge 6$, то есть элемента 7 с индексом 3).
